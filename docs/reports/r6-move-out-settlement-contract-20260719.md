# R6 退租結清帳本契約（2026-07-19）

## Owner 已確認的規則

1. 押金在帳務上以合約押金的**全額退款**記錄，不因水電、清潔或修繕費而改寫押金金額。
2. 退租費用是獨立的租客應收；現場採淨額給付時，系統以「租客將全額退款中的一部分支付多筆退租費用」的分攤紀錄呈現。
3. 人工憑證與註記是選填：現金可記租客簽收，匯款可記轉帳證明。
4. 付款完成、退款完成、正式關單不是由試算或分攤自動推論；R6 不提供 `closed` 狀態。

## 本輪可用範圍

- 建立與編輯 `draft` 退租費用明細。
- 顯示費用合計、押金／全額退款、人工確認的多筆分攤、建議實付退款、應收餘額。
- 由人工確認後轉為 `settled`；該狀態只表示費用與分攤已確認，**不代表付款或退款完成**。
- `settled` 僅可作廢；不可原地修改，亦不可轉為 `closed`。
- 清單支援物件、狀態與退租日期區間篩選，並可匯出 CSV/XLSX。
- 房東帳號只能建立、查看、匯出或操作其名下物件的結清單；越權物件篩選與單筆存取一律拒絕。

## 分攤規則

- 分攤項目限於同一結清單中的最後租金、電費、水費、管理費、前期未收、清潔費、維修費、其他費用。
- 每個項目的分攤額不得超過該項應收；分攤合計不得超過全額退款。
- 尚未決定自動分攤優先順序，因此系統不猜測或自動分配；操作人員必須在確認頁明確輸入各項分攤額。
- `應收餘額 = max(費用合計 - 分攤合計, 0)`；欠款仍留待代帳團處理。

## 明確禁止

- 不建立或修改 `PaymentRecord`。
- 不將退款寫成負數付款或負數費用。
- 不修改 `MonthlyBill.total`、合約押金或合約／房間狀態。
- 不依據備註、憑證文字或既有帳單 `paid` 布林值自動認列付款、退款或關單。
